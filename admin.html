Classes

Create classes and set their compulsory and elective subjects

Classes created here (e.g. SS1A, SS1B, JSS1A) appear on the registration form and everywhere a class is selected. Compulsory subjects are automatically added to every student in that class — no need to pick them individually. Elective subjects are the ones admin chooses per-student when creating or approving them.

Promotions

Move students up to their next class at the end of a session

Pick where each class should move to for the new session. Classes left on "Don't promote" are skipped entirely. Use "Graduate / Leave school" for a final-year class (this deactivates those students' portal access, same as Deactivate). Bulk Import Questions

Import many questions at once. Paste either the numbered format or CSV — the app detects which one it is.

Numbered format:
1. What is the capital of Nigeria?
A. Lagos   B. Abuja   C. Kano   D. Ibadan
Answer: B
Options can be on one line or separate lines. Answer line: Answer: B or Ans: B. Numbers: 1.  1)  1 — all accepted.
CSV Format:
question, optionA, optionB, optionC, optionD, correctAnswer
correctAnswer must be: a, b, c, d
Example: What is H2O?, Oxygen, Water, Salt, Acid, b
